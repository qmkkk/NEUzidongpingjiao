# neu自动评教

一个基于 Python 的 NEU 评教辅助脚本。

这个版本不接管登录，也不依赖浏览器驱动。使用方式是手动登录学校评教系统，进入“学生阶段评价二级页面”后，由脚本按你标定好的屏幕坐标自动点击 `评价`、填写分数并提交。

## 功能

- 手动登录后接管评教流程
- 支持连续处理多门待评课程
- 第 1 个评分项打 `5` 分，其余评分项打 `6` 分
- 每一行评分坐标都单独标定，避免按行距推算带来的偏移
- 提交后自动检测是否已经离开详情页，再继续下一门

## 文件

- `neu_eval_click_assist.py`：主脚本
- `neu_eval_click_assist_config.json`：本地标定坐标文件，不建议提交到仓库

## 运行

```powershell
python neu_eval_click_assist.py
```

## 首次使用

1. 手动登录学校系统。
2. 进入“学生阶段评价二级页面”。
3. 运行脚本并完成坐标标定。
4. 标定时需要记录：
   - 列表页第一条待评课程的 `评价`
   - 详情页每一行实际要点击的评分坐标
   - `提交` 按钮
   - 确认弹窗的 `确定/确认`

## 注意

- 浏览器窗口大小尽量固定，最好保持最大化。
- 标定完成后，后续运行会复用本地坐标文件。
- 如果页面布局变化，重新运行并选择重新标定即可。
